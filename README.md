# Vet Hero

## Project Purpose
Vet Hero is an offline-first educational vet game designed for ages 4–8. The project teaches young learners about animal care, empathy, and basic health habits through a simple interactive game.

## Setup Instructions
1. Download or clone the repository.
2. Open `index.html` in a web browser.
