# Vet Hero Master Governance Instructions

## Purpose
Vet Hero is an offline-first educational game built for kids ages 4–8. This repo is designed to remain accessible, safe, and easy to maintain while providing a clear governance structure for contributions.

## Governance Principles
- Keep the game simple, playful, and accessible for young learners.
- Prioritize offline-first behavior: all game assets should be available locally and able to run by opening `index.html`.
- Use plain HTML, CSS, and JavaScript only, unless a strong case is made for additional dependencies.
- Make all changes traceable with clear commit messages, PR descriptions, and QA documentation.

## Collaboration Rules
- Follow the engineering workflow in `docs/ENGINEERING_CHANGE_TEMPLATE.md`.
- Ensure every change is validated against `docs/QA_TEST_MATRIX.md`.
- Review and update governance docs as needed for new patterns or tools.

## Communication
- Use GitHub Pull Requests for all changes.
- Include a summary of what changed, why it changed, and how it was tested.
- Link to related governance docs and QA checklists in the PR description.
